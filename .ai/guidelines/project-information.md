# Project Information

## Project Name
Accounting Software

## Project Locale
en (English)

## Project Timezone
Asia/Tehran

## Design System
The design of this project should be neumorphism style.

## Color Palette
Use the dark galaxy indigo colors.

## Responsive Design
This project is only intended for the mobile devices and even on the desktop version it should show a mobile size layout.

### Desktop Version
On desktop devices you should show a centered mobile size layout of this project.

## Icons
This project uses the bootstrap-icons package. You can find the instructions at "vendor/twbs/bootstrap-icons/README.md".

## Purpose and Goal
This website is a personal minimal accounting project. The main goal of this project is to keep a track of my transactions.

## The `npm run build` Command
To run this command, you should use the window installed version since wsl does not provide the npm command.
