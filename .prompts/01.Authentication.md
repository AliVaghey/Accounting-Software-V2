# Task: Implement the Authentication System

## Summary
In this project users must be able to register and enter to their user panel and use the accounting features of this 
project. For this task you should implement the login and registration of the software.

## Login/Register
Unauthenticated users must only be able to see the login or register page. After the login they should be redirected to 
the home-page which you should leave empty for now.

## Current `/` URL
Currently, there is a welcome page at the "/" route. You should remove this. We don't need it. Instead, when users open the 
'/' page they should be redirected to the home-page if authenticated.
