# Task: Implement the Navigation Menu

## Summary
You should create a navigation menu bar at the bottom of all authenticated pages. You only need to implement the navigation menu and
not its pages.

## Implementation
You should create the navigation menu bar as a component and add it to the main layout view so that it will be present on all pages.

## Exception
The navigation bar must be on all pages except the login and register pages.

## Design
Create something beautiful and pretty.

## Position
You should make the navigation menu fixed at the bottom of all pages, it should stay in place when scrolling.

## Items
The navigation menu should have 5 buttons. 4 of them are link to different pages which you should leave empty for now. And the last one
is a modal toggle which opens a modal and is implemented using livewire.
The following list is the list of navigation items you should keep the same order:
1. Dashboard page link
2. Tags page link
3. Add Transaction Modal Toggle
4. Transaction list page link
5. Statistics page link

For each link you must use `wire:navigate.hover`.

## Items Design
For each item use a relevant icon and write the name of items with a small font size beneath each icon. 
For the middle add transaction modal toggle use only a plus icon with no text.

## Pages
Create empty views for each link, and later we'll fill them up.

## Add Transaction Modal
This modal should be empty for now but make sure to create a livewire component for it.
