# Task: Implement the Tags

## Summary
Each Transaction can have one or multiple tags attached to it. In this task you should only implement the tags page and functionality.
You must not do anything for transactions, we'll implement it later.

## Tags Page
The tags page should show a list of pretty cards for each tag. This list should show all tags and should not be paginated.

## Add Tag
At the top of the tags list page you should place an add button. This button should trigger a modal.
In this modal, user should be able to select a color and a name for the tag.

## Tag Cards
Tag cards must be beautiful. You should use the tag color for the card itself. Each card should have a delete and edit button.
The edit button should trigger a modal similar to the tag creation modal.

## Model
To implement tags, you should create a model called "Tag". It should hold the id, color, and name of the tag.
