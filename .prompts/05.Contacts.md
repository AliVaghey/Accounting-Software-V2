# Task: Implement the Contact Model and Page

## Summary
Each Transaction which will be implemented in later tasks can be linked to a specific person. For this we need a 
contact model to hold the information of each people.

## Model
The "Contact" model should have the following columns:
1. id
2. name
3. profile photo (optional)
4. updated_at
5. created_at

## Contacts Page
The contacts page which was created in previous tasks is currently empty. You should fill this page with the list of all
contacts. The contact list must be an infinite scrolled list.
This page should show a two column list of contact cards.

## Contact Card
Each contact card should have a profile photo circle at the top and the name of the contact at the bottom.

## Add Contact
You should add a modal toggle at the top of the contacts list which opens a modal to add new contacts.

## Edit, Delete, and Profile
When user clicks on each contact card, three buttons must appear beneath the card. One button to open the edit modal and another to delete
the contact. The third button is a link to the contact's profile page. You should leave the profile page empty for now.
By default, The delete and edit and profile buttons must be hidden. You should use icons for these buttons with no text.
