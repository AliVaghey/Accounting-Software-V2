# Task: Implement the Transactions

## Summary
Users should be able to create, edit and delete transactions. You should create a model for transactions.

## Transactions Table Columns
The transactions table and model should have the following columns:

1. id
2. amount
3. contact_id (nullable)
4. description (string - nullable)
5. updated_at
6. created_at

## Add Transaction Modal Toggle
The third item of the button navigation is a modal toggle to add transactions.

## Add Transaction Modal
In the add transaction modal, the first input should be the amount of transaction. The amount of transaction should be separated by thousands in 
real time with alpine js. The amount input should have the "inputmode='numeric'" HTML attribute so that the user keyboard be set to numbers.
The second input should be a text area for description which is optional.
The third section should show a compact list of all tags with their color. Users can select and attach none, one, or multiple tags to a transaction.
Keep in mind that later, we need to sort, categorize, and get some statistics of transactions based on their tags so implement it in a way
that our later goals be easy and possible.
The fourth section should be an infinitely scrolled list of contacts. Users can select none or one contact for transaction. the selected 
contact id will be stored on the transaction model. Selecting a contact for transactions is optional.

## Transactions Page
There is an empty transactions page which you should fill with an infinitely scrolled list of latest transactions.
Each transaction card should show all the information of transactions except the id, updated_at. The created_at should be shown in 
Persian calendar format.

## Edit and Delete Transactions
When a transaction card is clicked there should appear two buttons underneath it. One for edit and one for delete.
To Edit transactions you should show a modal similar to the add transaction modal. And to delete a transaction you should ask for confirmation.
