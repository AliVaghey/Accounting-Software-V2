# Task: Implement the Dashboard Page

## Summary
The dashboard page should show a compact overall information of accounting.

## Sections
The dashboard page must have the following sections with the same order:
1. Today date
2. Statistics card
3. recent transactions

### Today Date
You should show one line for the today date. The date should be in Persian calendar(Shamsi).

### Statistics Card
You should create a card to show the statistics of the current Persian month. You should show a pi-chart of the tags which where present in
the current month transactions. You should show each tag based on its color and percentage on the pi-chart. Do not use the tags name on the
pi-chart just show its color but underneath the pi-chart you should write each present tags with their name, color, transaction amount, and percentage.
For example, you should show the Uber tag was present in 40% of transactions of the current month and 3,000,000 was the total amount of its transactions.

### Recent Transactions
In the final section of the dashboard you should show the last 30 transactions. This should be a lazy loaded livewire component, after the whole page
loaded this component should get loaded.
